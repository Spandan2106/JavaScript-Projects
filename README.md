# JavaScript Projects

A collection of JavaScript projects, interactive web applications, and frontend/backend utilities built while exploring core JavaScript concepts, modern web APIs, and scalable application architecture.

## Overview

This repository houses a curated set of JavaScript projects ranging from DOM manipulation and client-side tools to full-stack and real-time web applications. Each project is organized in its own folder so you can inspect, run, and extend individual modules independently.

## Tech Stack

- **Languages:** JavaScript (ES6+), HTML5, CSS3
- **Frontend / Runtime:** React.js, Node.js, Express.js (where applicable)
- **Tools & Testing:** Git, GitHub, npm, Postman

## Getting Started
Clone the repository:

```Bash
git clone [https://github.com/Spandan2106/JavaScript-Projects.git](https://github.com/Spandan2106/JavaScript-Projects.git)
cd JavaScript-Projects
```
## Open a project:

Static / Browser projects: Open the project's index.html file directly in your browser or serve it using a local development server (such as VS Code Live Server).

Node.js / npm projects: Navigate into the project folder, install dependencies, and start the app:

```Bash
cd <project-folder>
npm install
npm start
```
